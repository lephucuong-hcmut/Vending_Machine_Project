# Vending Machine Project

#Overview

Our vending machine project is designed based on the fundamental functions of an automatic vending machine, with the following specifications:

#Features

1. Display Product Information

Displays product name, quantity, and price. Information is shown on an LCD screen. Users can navigate through available products using buttons.

2. Select Product and Quantity

Users select the desired product and quantity using switches. If a mistake is made, users can use buttons to go back and reselect the product or quantity.

3. Display Payment Information

The total amount to be paid is displayed on the LCD screen. Users can use buttons to go back and modify their selections if needed.

4. Enter Payment Amount

Users enter their payment amount using switches. If users forget the total cost, they can use a button to return to the payment information screen.

5. Payment Processing

The system compares the entered amount with the required payment: 
If the amount is sufficient, the system proceeds with dispensing the item.
If the amount is insufficient, an error message is displayed.

6. Dispense Item

The system simulates item dispensing using LEDs. If there is any change, it will be displayed on the LCD screen.

7. Update Inventory

The system updates inventory after each successful transaction.

8. Administrator Functions

Administrators can update inventory using switches and buttons, similar to the purchasing process.

9. User Notifications

The system uses LEDs and the LCD screen to notify users about the current stage of the process.

This project aims to create a functional and interactive vending machine simulation using hardware components such as buttons, switches, LEDs, and an LCD screen.
